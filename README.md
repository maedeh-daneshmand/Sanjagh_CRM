# سامانه مدیریت ارتباط با مشتری «سنجاق» (Sanjagh CRM)

یک نرم‌افزار حرفه‌ای، سریع و مدرن CRM بر پایه معماری Next.js 14، الهام‌گرفته از **CRM دیدار** و طراحی مدرن Apex Dashboard، مجهز به دستیار هوش مصنوعی، پایپ‌لاین کانبان، تقویم جلالی، اتوماسیون‌های فروش و پنل سفارشی‌سازی ظاهر و تم‌ها.

---

## 🌟 امکانات و قابلیت‌های کلیدی

### ۱. رابط کاربری، تم‌ها و چیدمان (UI & Customization)
- **چیدمان کاملاً راست‌به‌چپ (RTL):** همراه با فونت استاندارد و زیبای **وزیرمتن (Vazirmatn)**.
- **نمایش اعداد به صورت استاندارد انگلیسی (Latin Digits):** خوانایی بهینه برای ارقام پولی، تلفن‌ها و درصدها.
- **کشوی شخصی‌سازی ظاهر (Customize Drawer):**
  - **حالت تم:** روشن (Light)، تاریک (Dark)، خودکار سیستم (System).
  - **پالت رنگ‌های سازمانی:** زمردی (Emerald - پیش‌فرض)، آبی (Blue)، بنفش (Violet)، رز (Rose)، نارنجی (Orange)، سنگی (Slate).
  - **چیدمان نوار ابزار و منو:** سایدبار کامل، مینی (فقط آیکون)، فشرده، شناور، نوار بالا (Top Nav) و ترکیبی.
  - **تراکم نمایش:** فشرده (Compact)، استاندارد (Comfortable)، باز (Spacious).
  - **سوییچ فوری نقش کاربری (Demo Acting Role):** جابجایی بلادرنگ بین مدیر ارشد (ADMIN)، مدیر فروش (MANAGER) و کارشناس (SALES).

### ۲. پیشخوان فروش و شاخص‌های کلیدی (Dashboard)
- ۴ کارت شاخص عملکرد (KPI): کل درآمد فروش، مخاطبین فعال، معاملات بسته شده، ارزش باز پایپ‌لاین به همراه درصد رشد ماهانه.
- نمودار تعاملی روند درآمد ماهانه (Area Chart با Recharts).
- نمودار سهم کانال‌های ورود سرنخ‌ها (Donut Chart).
- جدول آخرین معاملات جاری و تایم‌لاین زنده فعالیت‌ها.

### ۳. مدیریت مخاطبین و سرنخ‌ها (Contacts & Leads)
- تفکیک هوشمند **مشتریان (Customers)** و **سرنخ‌ها (Leads)**.
- جدول پیشرفته با جستجوی چندفیلدی، برچسب‌های رنگی و ثبت مشتری جدید.
- محاسبه **امتیاز حرارتی سرنخ (Lead Score)** از ۰ تا ۱۰۰ بر اساس منبع، اولویت و سابقه تماس.
- دکمه **تبدیل سرنخ به مشتری (Lead → Customer)** با حفظ کامل تاریخچه فعالیت‌ها.

### ۴. پروفایل ۳۶۰ درجه مخاطب (`/contacts/[id]`)
- کارت مشخصات هویتی، آدرس، تلفن و وضعیت اختصاص به کارشناس.
- تایم‌لاین زمانی تعاملی (تماس‌ها، جلسات، یادداشت‌ها، پیامک‌ها).
- فرم ثبت سریع یادداشت و ثبت مکالمات تلفنی.
- **خلاصه هوشمند AI و گام بعدی:** تحلیل ۳۰ فعالیت آخر، تخمین درصد موفقیت و ارائه گام بعدی مذاکره.
- **یادداشت هوشمند (Smart Note):** استخراج وظایف خودکار و پیشنهاد تغییر مرحله معامله به همراه کارت‌های تأیید (Approve) و رد (Reject).

### ۵. قیف فروش و پایپ‌لاین کانبان (`/pipeline`)
- برد ۶ مرحله‌ای:
  1. سرنخ جدید (NEW)
  2. تماس و ارزیابی (CONTACTED)
  3. پیش‌فاکتور و دمو (PROPOSAL)
  4. مذاکره نهایی (NEGOTIATION)
  5. بسته شده برنده (WON)
  6. از دست رفته (LOST)
- مجموع مبالغ و تعداد معاملات در هر ستون با تفکیک رنگی.
- دکمه‌های جابجایی گام‌به‌گام و فرم ثبت معامله جدید.

### ۶. وظایف و تقویم جلالی (`/tasks` & `/calendar`)
- تب‌های وظایف: همه، معوقه‌ها (Overdue با شمارنده هشدار قرمز)، وظایف امروز، آینده و تکمیل‌شده.
- تقویم شمسی ماهانه با نگاشت وظایف و جلسات به روزهای ماه با امکان ثبت برنامه جدید.

### ۷. مدیریت تیم و عملکرد (`/team`)
- جدول ارزیابی کارشناسان فروش: تعداد سرنخ، معاملات برنده، نرخ تبدیل، درآمد فروش و وظایف معوقه.
- قابلیت **بازتخصیص دسته‌جمعی سرنخ‌ها (Bulk Reassign)** بین کارشناسان.

### ۸. کمپین‌های پیامکی و ایمیل (`/campaigns`)
- ساخت کمپین با کانال‌های SMS (کاوه‌نگار) و EMAIL (SMTP).
- استفاده از متغیر شخصی‌سازی نام مشتری `{{fullName}}`.
- نوار پیشرفت زنده صف ارسال پیام‌ها و آمار موفقیت/شکست.

### ۹. موتور اتوماسیون و طراح بصری (`/automations`)
- سناریوهای آماده (Presets):
  1. خوش‌آمدگویی سرنخ جدید (پیامک فوری + وظیفه فردا).
  2. یادآوری رهاشدگی سرنخ بعد از ۷ روز.
  3. تبریک و آنبوردینگ معامله برنده (Deal WON).
  4. نظرسنجی دلایل باخت معامله (Deal LOST).
- طراح بصری نموداری (Visual Flow Builder) با قابلیت تست زنده.

### ۱۰. دستیار هوش مصنوعی سنجاق (`/ai-assistant`)
- نگارش هوشمند پیام‌های پیگیری (Follow-up) با انتخاب لحن (دوستانه، رسمی، کوتاه، ترغیبی).
- قابلیت کپی سریع و ارسال در صف پیامک.

## 🛠️ پشته فناوری (Technology Stack)
- **فریم‌ورک:** Next.js 14 (App Router) + React 18 + TypeScript
- **استایل‌دهی:** Tailwind CSS + shadcn/ui + Tailwind Animate
- **دیتابیس و ORM:** PostgreSQL + Prisma ORM
- **کش و صف ارسال:** Redis + BullMQ
- **نمودارها:** Recharts
- **تاریخ شمسی:** Jalaali-JS (با ارقام لاتین)
- **تست‌ها:** Vitest
- **استقرار:** Liara (پلتفرم ابری لیارا)

## 🚀 راه‌اندازی محلی (Local Setup)

۱. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

۲. **اجرای سرویس‌های محلی (PostgreSQL & Redis با داکر):**
   ```bash
   docker-compose up -d
   ```

۳. **تنظیم متغیرهای محیطی:**
   فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید.

۴. **تولید کلاینت و سید داده‌های آزمایشی دیتابیس:**
   ```bash
   npm run db:generate
   npm run db:push
   npm run db:seed
   ```

۵. **اجرای نسخه توسعه:**
   ```bash
   npm run dev
   ```
   سپس به آدرس [http://localhost:3000](http://localhost:3000) مراجعه کنید.
